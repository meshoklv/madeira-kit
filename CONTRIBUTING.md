# Contributing

Compatibility reports, new measured configs and script fixes are welcome.

- **Report format:** device + iOS version, Madeira commit, game/version, config used, a log (`scripts/pull-log.sh`) or the analyzer output, FPS numbers with how you measured them. Mark facts vs. guesses.
- **Scope:** setup scripts, configs, measurements, notes. **Out of scope and will be rejected:** anything that circumvents copy protection or anti-tamper, save editors, game files or extracts, cracked executables, links to pirated copies.
- **Code changes to Madeira/Wine/FEX/DXMT** belong upstream; add a reference patch here only after opening the upstream PR.
- Keep personal identifiers (Team ID, UDID, Apple ID, certificate names) out of commits.
