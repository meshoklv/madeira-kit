# DS3: что разработчики Madeira делали для скорости тяжёлых игр и что из этого годится DS3

Дата: 20.10.2026. Источник: `<build-tree>/src`, `upstream/main` @ 9c0d814 (после `git fetch upstream`).
Пометки: **[коммит]** — число/факт из текста коммита или комментария в коде/каталоге настроек;
**[вывод]** — моё суждение о применимости к DS3, не мерил.

## Что есть в истории (важно для доверия к выводам)

- В `upstream/main` всего **50 коммитов** (12.10–15.10.2026), это сквош-«волны»: тексты отдельных
  коммитов (где «each message has the evidence») не сохранились, цифры есть только в телах сквошей,
  в комментариях кода и в `ConfigCatalog.generated.swift` / `GameRecommendations.swift`.
- **Crysis, Civ VI, Metro в истории не упоминаются вовсе.** Есть: GTA V Enhanced, RDR2, Horizon Zero
  Dawn, Ghost of Tsushima, God of War. Civ VI упоминается только в наших DS3-доках (madsync не стартовал).
- Ключевые perf-коммиты: a259011 (#297 питание/QoS/диагностика), daf2ca3 + 9db61d5 (#294 wineserver),
  86810d1 (#299 pso-warm), 05c5a89 (#292 pin DLL), 7f03ea0 (#298 JIT env), 8a7e8d2 (#318 thermal-лог),
  7828bab (#319 Game Mode), c877f28 (рекомендации по играм). Шапка `build/madsync/madsync.c` — про
  «~10 FPS, ни один поток не загружен, ~18 000 запросов/с к серверу».

## Главный факт о железе из истории [коммит]

`server_ios.c` (a259011, комментарий к `MADEIRA_POWER_GOV_MW`): **SoC зажимает CPU после ~250 Дж
энергии, потраченной выше ~2,3 Вт** (6 прогонов, разброс 3 %). GTA V: зажим на P 1,31 / E 1,70 ГГц
через 404–462 Дж — их съели загрузки при 3–5 Вт. HZD: зажим после ~273–330 Дж, «большая часть в меню и
загрузках при 2,75–3,8 Вт». RDR2: меню на 57–60 FPS 2 мин → зажим до геймплея.
DS3 [факт из наших логов]: меню 60 FPS при 3,4 Вт, после `fair`/`serious` P-ядра 2,8–3,4 → 1,5–2,2 ГГц.
Это та же картина: **бюджет сжигается в меню/заставках, а платит геймплей.**

## Топ-5 непроверенных для DS3 (по одному на прогон, та же сцена, сравнивать `[xp]`/`[srv-req]`/FPS)

Текущая база: `pool-split = 1`, `pool-low = 1`, `env.MADEIRA_X64_IMAGE_NOCOPY = 1`, `env.MADEIRA_LOCK_ORPHAN = stamped`.

1. Madsync — главная ставка, бьёт в 13–17 тыс. запросов/с (проверка: строка `[madsync]` без `disabled`, `[srv-req]` на порядок меньше):
```
inproc-sync = 1
```
2. Если madsync не стартует/ломает — вместо него запросы на своём потоке:
```
env.MADEIRA_SRV_DIRECT = 2
env.MADEIRA_FASTSYNC_SEM = 1
```
3. Регулятор FPS по мощности — чтобы меню/заставки не сжигали ~250 Дж до геймплея (геймплей 15–29 FPS ниже нижнего кэпа 30 не трогается):
```
env.MADEIRA_FPS_GOV_MW = 2000
env.MADEIRA_FPS_GOV_MIN = 30
```
4. Без сэмплеров, останавливающих потоки:
```
env.MADEIRA_LEAN_DIAG = 1
```
5. Служебные потоки на E-ядра:
```
env.MADEIRA_ECO_NATIVE = 1
```
Условный 6-й (только если в `[xp-t]` видно steam.exe/steamwebhelper.exe с заметным временем):
`env.MADEIRA_BG_QOS_PROCS = steam.exe;steamwebhelper.exe` [вывод].

Не трогать: `env.MADEIRA_POWER_GOV_MW`, `eco = 1`, `env.MADEIRA_SRV_ECO_FOLLOW` — уводят работу на E-ядра (у GTA V — падение).
