# DS3 на iPhone Air: безопасные настройки удобства (UX)

Дата: 20.10.2026. Источник: `<build-tree>/src` (ConfigCatalog.generated.swift, GameRecommendations.swift,
docs/CONTROLLERS.md, LIBRARY.md, STEAM_CLOUD.md, JIT.md, dxmt/winemetal, audio_null_ios.c).
**[факт]** — прочитано в исходниках; **[версия]** — мой вывод, не мерил на телефоне.
Исходная точка: 18–25 FPS, упор в CPU (главный поток), нагрев через несколько минут. MetalFX — исключён.

Куда писать строки: Game details › Advanced › **This game's config** (ключ игры важнее общего madeira.cfg).
Почти все ключи читаются при старте сессии — после правки перезапустить игру.

## Включить точно

```
# уже есть
pool-split = 1
pool-low = 1
env.MADEIRA_X64_IMAGE_NOCOPY = 1
env.MADEIRA_LOCK_ORPHAN = stamped
env.MADEIRA_PAD_EARLY_SLOT = 1
env.MADEIRA_CONTROLS_XBOX_DEFAULT = 1
# добавить
env.MADEIRA_EC_HOOK_TRACE = 0
env.MADEIRA_FPS_CAP = 20
env.MADEIRA_LEAN_DIAG = 1
env.MADEIRA_ECO_NATIVE = 1
```

| Строка | Что даёт | Почему безопасно |
|---|---|---|
| `env.MADEIRA_EC_HOOK_TRACE = 0` | Выключает служебный «репортёр», который читает код игры. Он **есть в рекомендуемом наборе DS3** (GameRecommendations.swift, `darkSoulsIII`), а в текущем конфиге его нет | [факт] «only logs, so turning it off costs a game nothing» |
| `env.MADEIRA_FPS_CAP = 20` | Ровный кадр 50 мс вместо скачущих 18–25; меньше работы CPU → меньше тепла | [факт] таймерное ожидание (не спин), любое значение 10–120, действует меньшее из кэпа и FPS limit. [версия] 20 FPS = ровно 3 обновления экрана при 60 Гц и 6 при 120 Гц — без дёрганья; 24 FPS при 60 Гц даёт чередование 33/50 мс (дрожь), поэтому **20, а не 24**. Откат — удалить строку |
| `env.MADEIRA_LEAN_DIAG = 1` | Убирает выборщики, которые каждые 20 с **останавливают все потоки** (микрофризы), обходы памяти реже | [факт] `[xp]`, `[xp-t]`, `[xp-api]` остаются; `[gpu-perf]` — лог DXMT, его не касается |
| `env.MADEIRA_ECO_NATIVE = 1` | Служебные потоки (прогрев JIT-пула, «лекарь» указателей) уходят на энергоэффективные ядра | [факт] «neither does work a frame waits for»; сервер, звук, интерфейс остаются как были |

В интерфейсе:
- **FPS limit** (Game details / меню сессии) — 30. С кэпом 20 действует меньшее; если кэп убрать — меню и заставки не будут греть чип на 60 FPS.
- **Settings › Display › Hold the display at its maximum rate** (`MADEIRA_PROMOTE`) — оставить **выключенным**: держит экран на 120 Гц, лишний расход.
- **Steam Cloud saves** — включено по умолчанию. Перед выходом: меню сессии › **Upload saves and close Madeira** (иначе сейв уйдёт в облако только при следующем запуске). Бэкапы автоматически: Файлы › `Madeira/Steam Cloud Backups/Dark Souls III (374320)/<время>/device|cloud`. Облако ничего не удаляет; конфликт — выбор на странице игры. [факт] STEAM_CLOUD.md.
- **Settings › JIT › Madeira JIT shortcut** (`env.MADEIRA_JIT_SHORTCUT = 1`) — JIT на мобильном интернете, где LocalDevVPN не работает. [факт] JIT.md.

### Управление (тач)
Встроенный «Xbox controller» уже имеет L3/R3 рядом со стиками, но маленькие (масштаб 0.62 от базового).
1. Меню сессии › **Controller layout** › **Create new layout** (свой «Custom Layout 1», встроенный не портится).
2. **Edit controls**: щипком увеличить **R3** (захват цели) до размера кнопок A/B/X/Y и поставить **над правым стиком, ближе к краю** — большой палец дотягивается без съезда со стика. L3 в DS3 почти не нужен — можно уменьшить.
3. **B** (перекат / удержание = бег) — сделать крупнее всех, остальные A/X/Y вокруг. RB/RT, LB/LT — в верхних углах крупнее (атака/блок под указательными на грани телефона). Удержание работает обычным удержанием кнопки.
4. **Opacity** 0.4–0.5 (по умолчанию 0.7, диапазон 0.15–1), **Size** 1.1–1.2 (0.5–2) — в Game details или в меню сессии. Раскладка запоминается за игрой.
- Вибрации телефона от игры на тач-контроллере нет — у тач-слота нет моторов.

### Физический геймпад
- Режим по умолчанию **XInput** (`MADEIRA_PAD_MODE` не трогать): DS3 на ПК ждёт Xbox-геймпад, DualSense тоже станет «Xbox». HID/DualSense-режим — не нужен.
- **Подключить до запуска игры**: DS3 ищет геймпад только на старте (для этого и стоит `PAD_EARLY_SLOT`).
- Вибрация `MADEIRA_PAD_OUTPUT` — включена по умолчанию; [факт] CONTROLLERS.md: моторам нужна доработанная xinput-библиотека Wine, в текущей готовой сборке может не доходить.

## Можно попробовать (с риском)

| Строка / шаг | Что даёт | Риск |
|---|---|---|
| `env.DXMT_LOG_LEVEL = error` | Режет ~145 строк/с info/warn-лога DXMT. [факт] `[gpu-perf]` пишется уровнем ERR (dxmt_command_queue.cpp:261) — **остаётся**, в отличие от `none` | Теряются предупреждения DXMT для разбора вылетов. Проверить в первом логе, что `[gpu-perf]` на месте |
| `env.WINEDEBUG = err+all,err-virtual,fixme-all` | Меньше строк Wine | Меньше данных для разборов |
| Кэп вместо 20 — регулятор: убрать `FPS_CAP`, поставить `env.MADEIRA_FPS_GOV_MW = <N>`, `env.MADEIRA_FPS_GOV_MIN = 20`, `env.MADEIRA_FPS_GOV_MAX = 30` | Держит среднюю мощность CPU на N мВт, переключая кэп 30↔24↔20 (не чаще раза в 3 с) | N сначала снять из `[xp]` (энергия) в бою; шаг 24 при 60 Гц может дрожать [версия]. Не путать с `MADEIRA_POWER_GOV_MW` — тот уводит потоки игры на слабые ядра → **минус FPS**, не брать |
| `env.MADEIRA_AUDIO_LEAD_MS = 120` | Если при нагреве трещит звук — больший запас аудио (по умолчанию 60 мс) | +60 мс задержки звука |
| Resolution › «This screen's shape» (лёгкий, ~944×656) или 720p + Aspect & scaling **Fit** | Меньше пикселей → GPU меньше греет общий чип [версия] | Картинка мыльнее; DS3 может сам добавить полосы при нестандартном соотношении. **Fill** обрезает края HUD |
| Настройки в самой игре: тени/эффекты/дальность — Low | Меньше вызовов отрисовки → меньше работы главного потока | Картинка |
| Ручной бэкап `DS30000.sl2` (Файлы › префикс Dock › AppData/Roaming/DarkSoulsIII) перед экспериментами | Страховка сверх облачных бэкапов | — |

## Не трогать
- `env.DXMT_LOG_LEVEL = none` — убивает `[gpu-perf]`.
- `eco = 1`, `env.MADEIRA_POWER_GOV_MW`, `env.MADEIRA_SRV_ECO_FOLLOW` — увозят потоки игры на слабые ядра, при упоре в CPU = меньше FPS.
- `metalfx-upscale` — проверено, хуже. Frame generation — артефакты и +задержка.
- `quiet-log`, `async-present-ahead`, `d3d12-shader-pack` — только Direct3D 12; DS3 — Direct3D 11.
- `env.MADEIRA_PRESENT_LIMITER = 1` — экспериментальное A/B темпа кадров, по умолчанию выключено.
- Кэш шейдеров (`shader-cache`, DXMT) и быстрый старт сервера (`MADEIRA_FAST_SERVER_START = 1`) уже включены по умолчанию.

## Как проверить
Один и тот же участок (бой у Firelink / Высокая стена), 10 мин: в логе `[xp]` (мощность CPU, частоты),
`[gpu-perf]` (fps, мс/кадр), `[thermal]` (когда наступает serious). Сравнить с прогоном без новых строк.
