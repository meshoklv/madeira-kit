**Разрешение** [факт]: `display-shape resolution=1408x648`, `first drawable 1408x648` — игра рисует в 1408×648 (0.91 Мп),

## 5. План

### Эксперименты (по одному изменению на прогон, та же сцена, сравнивать с этим логом)

**1. GPU: 1040×480 + MetalFX 1.5×** — ставка на сцену B (GPU 64 %).
Game details › Display › MetalFX upscaling **1.5×**, Resolution **1040×480 · for MetalFX 1.5×**, то же разрешение в DS3. В конфиге появится:
```
metalfx-upscale = 1.5
```
Ожидание: GPU 32 → ~18–22 мс/кадр в B, **B 19 → 22–25 FPS (+10–25 %)**, A без изменений; бонус — больше энергии CPU [версия].

**2. Сервер: семафоры в fastsync** (безопасный CPU-шаг):
```
env.MADEIRA_FASTSYNC_SEM = 1
```
Ожидание: `[srv-req]` req41 и select «first object: semaphore» почти исчезают; **+3–8 %** [версия].

**3. Сервер целиком: madsync** (вместо №2, не вместе):
```
inproc-sync = 1
```
Ожидание: запросов к серверу в разы меньше, главный поток меньше ждёт; **+8–20 %**, сильнее в сцене A [версия].
Не стартует/виснет Steam — убрать строку, вернуться к №2 и попробовать `env.MADEIRA_SRV_DIRECT = 2`.

Диагностика (не меняет планирование, но формально — изменение; добавить и оставить с этого прогона): `env.MADEIRA_POWER_PROBE = 1` —
покажет, правда ли GPU отбирает энергию у CPU в сцене B.
